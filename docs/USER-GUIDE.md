# 稿匠 · 使用手册（不需要懂代码）

> 稿匠是一台**纯单机**的公众号写作工具：AI 帮你从选题一路做到成稿，排版配图后一键发进微信草稿箱。
> 所有文章、密钥、设置只存在你自己电脑里，不经过任何服务器。

## 一、三分钟跑起来

1. **配 AI（必做，一次搞定）**：左下角「设置」→ AI 服务 → 服务商预设选 `DeepSeek` → 到 <https://platform.deepseek.com> 注册后点「API Keys → 新建」，把 `sk-` 开头的 Key 粘进「API Key」→ 点「测试 AI 连通」看到 ✓ → 「保存设置」。
2. **写一篇**：写作页点「新建」→ 标题栏填选题 → 点「AI 生成初稿」→ 不满意的地方：在正文**选中一段字** → 右栏点「更口语 / 去AI味 / 按要求改写」→ AI 只改你圈的那段，点「应用」才算数。
3. **发出去（两条路，任选）**：
   - **不配微信也能发**：写作页点「复制富文本」→ 打开公众号后台编辑器直接粘贴，**样式和本地图一起带过去**（图已内联，不用重新插）。个别图万一没显示：到配图页点那张图的「复制此图」→ 在后台图片位 Ctrl+V，微信会自动上传。这是最稳的路。发布页顶部有**四步发布清单**照着走即可；没配凭证时点「送草稿箱/立即发布」不会白跑报错，会直接给你清单入口。
   - **定时发布也不挑账号**：未配微信凭证照样能加入定时队列——到点走「提醒模式」：弹系统通知 + 发布页该任务变成「到点·等你复制发布」，一键跳去复制，不会静默失败。
   - **一键进草稿箱**：见下面第二节，配好公众号凭证后，发布页点「立即送草稿箱」或「定时发布」。

## 二、配公众号凭证（想做草稿/定时发布才需要）

| 字段 | 去哪拿 | 注意 |
|---|---|---|
| AppID | <https://mp.weixin.qq.com> 登录 → 设置与开发 → 基本配置 → 公众号开发信息 | 以 `wx` 开头 |
| AppSecret | 同上页面点「生成」 | **只显示一次**，当场复制；忘了就重新生成 |
| IP 白名单 | 同页面「IP 白名单 → 查看」 | 把稿匠状态栏显示的**公网 IP** 加进去，点状态栏 IP 可复制 |

填好点「连通性自检」：三步全绿就通了（自检按表单当前值直测，不必先点保存）。
**个人未认证订阅号大概率没有草稿/发布权限（报 48001）**——这不是故障，微信的权限规则如此，直接用「复制富文本」发布即可，效果一样。

## 三、五个页面干什么

- **写作**：左=文章库（可搜索），中=Markdown 编辑器+实时手机预览，右=AI 改写/回炉/审核。顶栏可换排版样式、成稿向导、AI 起标题；编辑器里 **Ctrl+S** 直接保存。首次打开会自动放一篇「3 分钟看懂稿匠」示例文章，把 8 套主题、高亮、图槽都演示了一遍——照着看完，改它或删它都行。
- **热点**（写作页左上切换）：微博/知乎/头条/抖音四榜，看到能写的点「用此选题」。
- **配图**：正文里每个 `[图槽: 画面意图]` 在这里排队显示。点「AI 生成提示词」拿画面描述（提示词会跟着文章保存，不丢），再点「AI 出图」在工具内直接生成候选图——出完先给你看，点「用这张落正文」才写进文章，不满意点「弃用」换提示词重试，AI 永远不擅自改正文。不想配生图 Key 也照样用：「选本地图片」或自己拿去任意生图工具出图后落位。生图服务在设置页配置（内置智谱 CogView 免费档 / 硅基流动 FLUX / 自定义端点，Key 经 DPAPI 加密只存本机）。已成图的卡片上有「复制此图」——把这张图按位图放进剪贴板，公众号后台图片位 Ctrl+V 即上传。发布时本地图自动转成微信图床；素材文件丢了导致图带不走时，预览和复制出的正文里会显形为「图片未随带」提示，不会静默丢图。
- **发布**：立即送草稿 / 立即发布 / 定时队列。定时任务到点先推草稿并弹系统通知，**最终点不点「确认发布」由你决定**。提交后微信的审核结果（成功/审核中/不通过）会每分钟自动回写到队列卡片上。页顶「发布通道」横幅会实时提示当前该走哪条路（未配凭证/自检异常时指向「复制富文本」，一键跳写作页并复制好）；API 发布失败时错误旁也有「改用『复制富文本』发布」按钮。
- **设置**：AI 服务（预设/温度/每个 Agent 单独模型）、公众号凭证、排版样式（内置 8 套：青竹绿/杂志灰/暖橙手账/静墨蓝/宣纸古雅/桃夭文艺/深海科技/暮山紫；可新建自己的配色，还能「导出我的样式」成 JSON 分享/换机恢复、「导入样式 JSON」直接用别人分享的样式，重名或格式不对会逐份说明跳过原因）、素材库。

## 四、人在回路（AI 的手刹在你手里）

- AI 所有改写都以「建议卡片」出现：应用/忽略你说了算；「撤销」随时反悔。
- 成稿向导六步（选题→调研→大纲→初稿→回炉→审核）：每步输出可编辑、可重跑、可跳过；回炉不满意点「恢复原稿」；定稿也要你手动保存。
- 素材库（设置最下方）：填你的真实经历（时间/地点/感受越具体越好），AI 写初稿和去AI味时会引用它们——这是降 AI 味最有效的弹药。

## 五、故障排查表

| 现象 | 原因 | 解决 |
|---|---|---|
| AI 测试失败：`401/invalid api key` | Key 抄错/已删 | 去服务商后台重新生成，重填保存 |
| AI 测试失败：超时/网络错误 | 断网或服务商宕机 | 看状态栏公网 IP 是否探测成功；换服务商预设试 |
| 自检报 `40164` | 本机公网 IP 不在白名单 | 点状态栏 IP 复制 → 公众号后台加白名单 → 再点自检 |
| 自检报 `48001` / `api unauthorized` | 账号无草稿/发布权限（未认证个人号常见） | 正常现象，改用「复制富文本」发布 |
| 自检报 `40001/40013` | AppSecret 错误或 AppID 抄错 | 后台重新生成 Secret 再填 |
| 公众号 IP 变了（重拨号/换网络） | 白名单里是旧 IP | 重新点状态栏 IP 查看新值并更新白名单 |
| 发布报「图片超过微信 1MB 限制」 | 单图过大 | 配图页换小图（<900KB 最稳） |
| 发布报「缺少封面图」 | 正文没有任何本地图 | 放一张本地图当首图，或它自动拿来做封面 |
| 定时任务没跑 | 到点时电脑关机/软件没开 | 「仅存草稿」任务开机后自动补跑；「发布」任务不擅自补发，会显示「错过时间·等你决定」——点「仍要发布」补发，或取消后重新定时；软件关窗不退出（托盘常驻） |
| 定时任务显示「到点·等你复制发布」 | 未接微信API，走了提醒模式 | 这不是报错：点「去写作页复制」→ 后台粘贴发布即可 |
| 队列卡片显示「发布状态查询受阻」 | 凭证删了/IP 变了 | 不影响已提交内容，去公众号后台看结果 |
| 提示「数据文件损坏，已自动备份」 | 断电等导致 JSON 损坏 | 损坏原文在数据目录 `.corrupted-*` 文件里；toast 点「打开数据目录」可找回，重填设置即可继续用 |
| 崩溃/强关后内容丢了 | — | 重开软件：未保存内容会自动恢复到编辑器并提示 |

## 六、数据都在哪 / 换电脑怎么办

设置 → 最下方「数据与备份」：
- **导出备份包**：一键把文章/设置/样式/素材/队列全量打成一个 JSON 文件，拷 U 盘/网盘即走
- **导入备份包**：新电脑上装好稿匠，选这个文件即全量还原；导入前会弹框让你确认（篇数/素材数/导出时间），现有数据会先自动存成 `.pre-import` 文件，导入错了也能找回
- **打开数据目录**：所有数据本来就是普通 JSON 文件，整目录复制走也算备份
- 只想分享自己调的配色？不用整包备份：设置「排版样式」卡片里的「导出我的样式」单独出样式 JSON，对方「导入样式 JSON」即可

密钥（AI/微信/生图 Key）用 Windows 系统级加密（DPAPI）存储，**绝不进备份包**——换电脑导入备份包后，只需重填一次 Key。
