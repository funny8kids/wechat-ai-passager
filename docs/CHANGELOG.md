## [Unreleased] — 配图一键出图（不再需要跳出工具）

### 新增
- **设置页「生图服务」卡片**：内置国内可达的文生图预设——智谱 CogView（cogview-3-flash 免费档）/ 硅基流动 FLUX.1-schnell / 自定义 OpenAI 兼容端点；模型、Base URL、尺寸随预设联动，「测试出图」不保存也能真实生成一张验证连通
- **配图页「AI 出图」按钮**：图槽卡片上一键出图（提示词可先「AI 生成提示词」再手改）；候选图先显示在卡片里标「待你确认」，点「用这张落正文」才写入文章（可撤销），「弃用」不污染正文——生图结果永远经人工确认落位（HITL）
- 生成的图片自动落素材库（`ai-时间戳` 命名），随「复制富文本」内联带图、发布时自动转微信 CDN，与本地选图同权
- 生图 Key 经 Windows DPAPI 加密只存本机（与微信 AppSecret 同等待遇），支持 `GJ_IMG_KEY` 环境变量引导；未填 Key 时报错直接指路「设置 → 生图服务」
- 测试门禁：新增 `test-imagegen.mjs` 34 项断言（假 fetch 离线测请求体/响应解析/错误映射/接线/HITL 顺序），`npm test` 全链 85 项

### 新增（③无API权限账号无死角）
- **发布页四步发布清单**：未接入微信 API 时，通道横幅从一句话升级为编号清单（确认成稿→复制→粘贴→后台预览发布），并明示「全程不需要任何 API 权限」「定时发布可用本页排队」
- **定时任务「提醒模式」**：未配凭证的定时任务到点不再白跑报错——自动转为「到点·等你复制发布」状态，弹系统通知指路，卡片一键「去写作页复制」；入队时即预告该行为
- **凭证短路**：未填凭证时点「立即送草稿箱/立即发布」不再发起注定失败的请求，直接显形正式方案并给「去复制/去接入」双出口；失败任务卡片新增一键改道「改用『复制富文本』」，48001 错误附人话解释
- **修复调度器真实缺陷**：`tick/runOne` 会把执行体自行转入的 `awaiting_confirm`（人工放行/提醒模式）覆盖成「完成」——即「定时到点等你放行」在真实调度路径下从未生效；现调度器尊重执行体转态，并加回归测试
- 测试门禁：新增 `test-noapi.mjs` 14 项接线断言；pipeline/scheduler 行为测试 +5 项（`npm test` 全链 104 项）

## [0.5.2] - 2026-09-21 — 「复制富文本」转正为正式发布方案

### 新增
- **发布页通道横幅**：进入发布页实时显示当前该走的发布路线——未配微信凭证/自检异常（40164、48001 等）时明示「复制富文本」为正式发布方式，并提供「去设置」「去写作页复制」一键直达；自检通过则确认 API 可用
- **API 发布失败一键改道**：送草稿/发布报错时，错误信息旁新增「改用『复制富文本』发布」按钮，点击跳写作页自动完成复制（配合 0.5.1 主进程剪贴板，失焦也不降级）
- 文档收口：USER-GUIDE/README 将「复制富文本」从"自动降级"表述升级为"正式发布方式"
- 设置页「单次最大输出 tokens」常显说明（0=不限制，用服务商默认），不再只靠 placeholder

## [0.5.1] - 2026-09-21 — 微信自检表单直测 + 复制富文本改主进程写剪贴板

### 新增
- **微信连通性自检支持表单直测**：填完 AppID/AppSecret 不必先「保存设置」即可点自检（留空字段回落已存凭证）；已用假凭证真实点击验证全链路：UI→主进程→微信服务器 40013→红叉显形+状态栏「API 异常」，凭证不落库

### 修复
- **「复制富文本」不再依赖窗口焦点**：旧实现走渲染层 execCommand，后台/失焦时静默只复制纯文本（实测剪贴板无 HTML Format）；改为经主进程 `clipboard.writeHTML` 直写 HTML Format。真实回读验证：剪贴板含 CF_HTML 头 + 31 处内联 style、0 个 `<style>` 块，粘贴公众号后台可保留排版

## [0.5.0] - 2026-09-21 — 稳定性加固 + 自助化（对标 OBS：不静默失败、不看代码能配置）

### 修复
- **数据丢失风险**：JSON 存储读失败不再当作"无数据"覆盖写盘；损坏文件自动备份为 `.corrupted-时间戳` 并提示（可一键打开数据目录）
- **Windows 并发写 EPERM**：同名文件并发保存串行化 + rename 重试（5 次退避），临时文件唯一命名 + fsync，杜绝崩溃点
- **调度器卡死**：启动时把中断的 running 任务恢复为 failed（可手动重试）并通知；「立即执行」改为单任务隔离运行，不再连带跑整队
- **渲染层静默失败**：队列取消/放行/立即执行、删除文章、AI 连通测试、公众号自检全部加错误显形与按钮恢复；调度器/存储异常经 `app-alert`/`store-corrupted` 事件落到 toast+系统通知

### 新增
- **崩溃保护**：编辑器 1.5s 防抖自动暂存（autosave），保存成功即清除；下次启动检测到未保存修改自动恢复并给出「丢弃恢复」选择
- **发布终态回写**：提交发布后每 60s 轮询微信 `/freepublish/get`，队列卡片显示「微信审核中…→✓ 发布成功 / ✗ 平台审核不通过」等终态并弹系统通知；立即发布也自动入队留痕跟踪（行为测试 10/10）
- **配图提示词持久化**：AI 生成/手改的画面提示词随文章保存，切页、重开不再丢失；空槽恢复占位文案
- 密钥可清除（设置页留空不再等于"不改"，后端区分 undefined/空串）；加密不可用时明示明文风险；「打开数据目录」IPC
- 预览/时间线中本地图自动转 dataURL 显示（`asset:dataUrl` 带缓存、12MB 上限、文件名防穿越）
- `npm test` 常驻行为门禁：store/scheduler 稳定性 15 项 + 发布终态轮询 10 项 + 定时发布流水线 12 项（转存/封面/放行/回写全链）

### 新增（自助化）
- **首启引导**：未配 AI Key 时启动即弹「去设置」引导；已配 Key 但缺公众号凭证时提示可跳过（复制富文本降级路径）
- **密钥自助管理**：API Key / AppSecret 旁加「清除」按钮（二次确认）；每项凭证标注「去哪拿」获取路径（DeepSeek 平台 / 公众号后台→基本配置、Secret 只显示一次、IP 白名单）
- **定时发布可选模式**：加入队列时可选「发布」或「仅存草稿」，到点行为与模式一致（有 12 项行为测试覆盖 draft 模式）
- **数据与备份卡片**：设置页一键打开数据目录（settings/articles/queue/autosave 全为 JSON，可直接备份迁移）
- **用户手册**：新增 [docs/USER-GUIDE.md](USER-GUIDE.md)——三分钟上手、凭证获取表、五页面说明、人在回路线、12 行故障排查表（401/超时/40164/48001/IP 变化/1MB 超限等）；README 快速开始接入手册链接

## [0.4.0] - 2026-09-20 — 好用起来：热点、标题、样式、Agent 参数、成稿流水线

### 新增
- **热点选题面板**：左栏「文章库/热点」切换；聚合微博/知乎/头条/抖音四大热榜（60s API，主进程代拉避 CORS，
  5 分钟缓存 + 断网回退旧缓存），一键「用此选题」新建文章并带入标题
- **AI 起标题**：按选题+正文给 7 个风格各异的候选（附风格标签与字数），浮层呈现；
  点「采用」才替换标题——纯建议，不擅自动手
- **多智能体成稿向导**：选题→调研→大纲→初稿→回炉→审核六步流水线；
  每步 AI 输出先进向导文本框，可编辑、重跑、跳过、恢复原稿，点「确认」才进入下一步；
  定稿送入编辑器后保存/发布仍是人的操作（HITL 全链路）
- **排版样式系统**：新文章默认样式可选；自定义样式增删改（重名/内置名保护），
  调色板+字号/行距/字距九项可调，编辑时实时渲染预览；写作台下拉区分「我的」与内置
- **设置页 AI 高级配置**：服务商预设（DeepSeek/Kimi/OpenAI/本地 Ollama）、全局温度滑杆、
  max tokens、六个 Agent（初稿/改写/标题/配图/调研/审核）各自模型与温度覆盖、
  「测试 AI 连通」不保存也能按当前表单直测
- 全局 `[hidden]` 显形修复；深链 `#hot`、`#demo-wiz-run-N`（向导第 N 步真实执行截图验证）

### 变更
- AIClient 支持 temperature/maxTokens 默认值与按 Agent 覆盖；`ai:agent` IPC 按 Agent 名跑单步
- 渲染入口 `renderWeChatHtml` 支持 themeOverride（自定义调色板）与排版三参数
