# 界面与交互设计规范

> 稿匠是**工具**，不是网站。一切界面决策以"桌面生产力工具"为基准（对标 OBS / 剪映的窗口心智），
> 禁止营销式落地页、禁止无限滚动信息流。

## 一、人在回路五定律（最高优先级，任何新功能不得违反）

1. **AI 只出建议**：所有 AI 输出以建议卡片呈现（原文/新文 diff 对照），只有两个动作——`应用到该段` / `忽略`。
2. **作用域由人圈定**：AI 的输入永远来自人的选区或勾选的段落；不存在"AI 改全文"按钮，也不提供等价变体。
3. **可撤销**：每次应用前压栈快照（≤50 步），toast 内直接给"撤销"入口。
4. **发布必须人工放行**：定时任务到点只推草稿 + 通知；`awaiting_confirm` 状态必须人点「确认发布」。无凭证时转「提醒模式」（等你复制发布），关机错过转「等你决定」——任何分支 AI/调度器都不替人按最后一下。
5. **降级透明**：API 权限不足 / AI 失败时，明确告知"现在能做什么、不能做什么"，不假装成功。

## 二、外壳与信息架构（v0.3 重设计）

外壳：左侧深色图标导航栏（写作/配图/发布 + 底部设置）+ 全宽工作区 + 底部状态栏。
编辑器是绝对主角（对标 doocs/md：编辑区最大化、布局可切换），杜绝"网站感"顶栏标签。

| 页 | 职责 | 关键控件 |
|---|---|---|
| 写作 | 三栏：文章库(搜索/删除) · 文档头+格式工具条+编辑/预览分栏(可拖拽) · AI 副驾面板；左上可切「热点」四榜 | 布局切换(编辑/分栏/预览)、复制富文本、图槽插入、段落勾选回炉、选区改写、建议卡片、成稿向导六步、AI 起标题、用此选题 |
| 配图 | 按正文顺序的"槽位→已成图"时间线；槽位出提示词，成图出真实缩略图 | AI 生成提示词、**AI 出图**（候选标「待你确认」，点「用这张落正文」才写入/可弃用）、选本地图片、**复制此图**、更换/移除、外链图版权警告条 |
| 发布 | **发布通道横幅**（实时指路：未配凭证/自检异常→指向复制富文本）+ 四步流程图(转存→草稿→放行→生效) + 当前文章操作 + 队列卡 | 状态 chip（排队中/执行中/完成/失败/到点·等你放行/**到点·等你复制发布**/**错过时间·等你决定** 呼吸提示）、确认/重试/取消/**改用复制富文本一键改道** |
| 设置 | AI 服务、公众号凭证 + 连通性自检、**生图服务**（免Key默认+自带Key预设+测试出图）、公网 IP、**排版样式**（8 套+我的样式导入导出）、素材库、**数据与备份**（导出/导入备份包+打开数据目录） | 密钥输入框"留空=不修改"、自检步骤结果表、备份包导入前确认框 |

状态栏常驻：保存态 / 调度说明 / API 自检 chip / 公网 IP chip / 保存按钮。
快捷键：Ctrl+S 保存、Ctrl+N 新建、Ctrl+B/I 加粗斜体。

## 三、视觉系统

- **主色**：微信绿 `#07a35a`（accent），AI 紫 `#5b5bd6`（AI 元素专用），底色 `#f5f6f8`，导航栏深灰 `#1c2128`
- **语义色**：ok=accent / warn=`#b45309` / err=`#c53030`，状态永远"色 + 文字"双通道，不单靠颜色
- **字体**：系统 UI 栈（PingFang SC / Microsoft YaHei），编辑器正文 14px/1.9 等宽栈，密度为工具密度
- **图标**：统一线性 SVG symbol 库（1.8 stroke），禁用 emoji 当图标
- **文章排版主题**（md2wechat THEMES，8 套）：青竹绿 / 杂志灰 / 暖橙手账 / 静墨蓝 / 宣纸古雅 / 桃夭文艺 / 深海科技 / 暮山紫，支持「我的」自定义样式与样式包 JSON 导入导出，导出为全内联样式 HTML

## 四、文案语气

- 说人话、给出路："把状态栏显示的公网 IP 加入公众号后台白名单后点重试"，而不是"操作失败 40164"
- AI 相关文案强调人的主导权："先勾选要回炉的段落（AI 不碰你没标记的文字）"
- 错误必须带下一步动作，不裸抛技术码

## 五、反馈与状态

- 一切异步操作：按钮禁用 + 文案变化（"生成中…"），完成后 toast
- 渲染层未捕获错误 → 底部红色显形条（不允许静默失败，见 ADR-009）
- 窗口关闭 = 隐藏到托盘（调度器驻留），退出只走托盘菜单，防止"以为关了其实停了定时"
