# 架构决策记录（ADR）

> 记录"为什么这么设计"。每条含：背景 → 决策 → 后果。推翻旧决策时不删除，
> 新增一条并标注 supersede，保留决策轨迹。

## ADR-001 单机工具，不租服务器
- **背景**：最初讨论过 Web 优先 + 云同步。用户明确约束："最好不租用服务器，当个工具使用，单机即可"。
- **决策**：Electron 桌面工具，所有状态存本机 `%APPDATA%\gaojiang\`，无任何自建后端。
- **后果**：无服务器成本与运维；代价是定时发布依赖本机进程驻留（托盘），多设备同步留待后期以"局域网直连"而非云端的方案解决。

## ADR-002 定时发布 = 本机调度器 + 人工放行，而非全自动
- **背景**：查证微信官方文档确认 `freepublish/submit` **不存在定时字段**，平台不提供定时发布 API。
- **决策**：本机 20s tick 调度器到点先推草稿箱并弹系统通知；默认 `confirmBeforePublish=true`，最终"发布"由人点击放行。状态机含 `awaiting_confirm`。
- **后果**：比"全自动"多一步操作，但符合人在回路原则，且机器休眠/断网导致失败时可重试 ≤3 次并留痕，不会静默误发。

## ADR-003 人在回路的硬性技术约束
- **背景**：用户核心诉求："完成后的文章不能让 AI 全改，需要根据人的意志来修改"。
- **决策**：架构上不给 AI 留"整篇重写"的路径——AI 输入永远是**人圈选的片段或勾选的段落**，输出永远是**建议卡片**（diff 对照），落稿只发生在人点"应用"时，且 `pushSnapshot` 支持撤销。`verify-article.mjs` 用断言"未标记段落逐字节不变"守住这条线。
- **后果**：交互比"一键 AI 改全文"重，但这是产品定位（人的文字 + AI 的辅助），不是缺陷。

## ADR-004 Electron 而非 Tauri
- **背景**：Tauri 产物小，但本机无 Rust 工具链，且微信 API/加密存储生态 Node 更顺。
- **决策**：Electron 33。产物 72MB 可接受。
- **后果**：包大；换来 safeStorage(DPAPI)、动态 ESM import、纯 Node 可测的 core 层。

## ADR-005 密钥用 DPAPI 机器绑定加密，密文与配置分离
- **背景**：用户自带 API Key / AppSecret，绝不能明文落盘或上传。
- **决策**：`secrets.json` 只存 safeStorage 加密后的 base64；渲染进程只拿到"是否已设置"布尔；支持环境变量一次性引导注入（`GJ_AI_KEY` 等），代码与 git 里永不出现明文 Key。
- **后果**：exe 拷到另一台机器需重填密钥——视为特性（防整包拷走盗用）。

## ADR-006 AI 接入 = OpenAI 兼容协议 + 用户自带 Key
- **背景**："api key 现用的对话模型顶一下就行"。不绑定单一供应商。
- **决策**：core/ai.mjs 只依赖 `/chat/completions` 标准面（含 SSE 流式），DeepSeek/Kimi/GLM/代理皆可；预置任务 prompt 集中在 `AI_TASKS` 注册表，改文案不改代码。
- **后果**：无法使用供应商私有高级特性（如联网搜索参数）——需要时在 core 加旁路，不影响主链路。

## ADR-007 配图采用"图槽"协议而非直接插 AI 图
- **背景**：图片位置是公众号第一要素；AI 生图有成本且未必被采纳。
- **决策**：初稿在情绪转折处插入 `[图槽: 一句话配图意图]` 文本标记；配图页把意图交给"美术指导" prompt 生成文生图提示词；人再决定用 AI 生图/本地图/授权网图落位替换槽位。审核规则检查未落实槽位与外链图风险。
- **后果**：图槽是纯文本，任何编辑器操作都不会丢；三源接入互不干扰（见 ARCHITECTURE 扩展点表）。

## ADR-008 发布链路对 48001（无 API 权限）预设降级
- **背景**：未认证个人订阅号大概率无草稿/发布 API 权限（48001），这是全项目最高风险项。
- **决策**：自检失败不阻塞产品——写作/排版/渲染/图槽全部本地可用，发布降级为"生成微信可粘贴的排版内容"。设置页自检把 40164（IP 白名单）/48001 的处置指引直接呈现给人。
- **后果**：工具对任何账号类型"可用"，全自动体验取决于账号资质。

## ADR-009 渲染层零构建、经典脚本、按功能域分文件
- **背景**：无打包器、无框架，file:// 下运行；曾因单文件 app.js 一处语法错误导致**整个渲染层静默失效**而进程与窗口看起来完全正常。
- **决策**：不用 ESM `<script type=module>`（file:// CORS 限制），用加载顺序明确的经典脚本按功能域拆分（util/editor/images/publish/settings/boot）；配套 `npm run lint` 语法门禁 + 渲染层全局错误显形条，杜绝"静默死亡"。
- **后果**：全局命名需自律（各文件顶层声明不重名）；规模再涨 3 倍时应引入构建器，届时新增 ADR supersede 本条。

## ADR-010 依赖安装必须走 npmmirror
- **背景**：本机网络访问官方 npm registry 超时（实测 ETIMEDOUT）。
- **决策**：所有 npm/electron/electron-builder 二进制下载统一镜像源（文档与脚本内写明环境变量）。
- **后果**：无。纯环境约束。

## ADR-011 「复制富文本」转正为主发布通道（supersede ADR-008 的"降级"定位）
- **背景**：未认证个人号 API 报 48001 是常态而非例外（ADR-008）；实测粘贴链路样式/本地图可完整带走。
- **决策**：复制富文本从"备胎"升格为**正式交付通道**——正文本地图自动 dataURL 内联（粘贴即显形），缺失显形「图片未随带」，配图页逐张「复制此图」位图兜底补图；API 草稿/发布改为可选加速器。发布页横幅实时指路，失败一键改道。
- **后果**：①③两条硬伤以通道反转消解；exe 级剪贴板回读 7/7 留证（HTML 内联样式+data:image、位图逐字节一致）。

## ADR-012 生图默认「免费直连（免Key）」零配置出图
- **背景**：同类工具生图普遍要注册换 Key，与"装好即用"定位冲突；实测免费端点 GET 直返图片字节可用。
- **决策**：免费直连设为默认源（魔数嗅探防伪 200 错误页、flux 池避开默认限流），免费档三条限制如实公示（水印/中文长提示词偏弱/高峰拥堵）；高峰 429/5xx 自动换 seed 重试一次，仍堵人话显形并指路切自带 Key 源（智谱 CogView/硅基流动/自定义，Key 走 DPAPI）。
- **后果**：出图不跳出工具、不强制配 Key；对上游共享池的可用性存在诚实依赖，已用文案与改道出口兜住。

## ADR-013 备份/迁移包对密钥双向硬拒
- **背景**：单机单点风险的根治是整体搬数据，但 DPAPI 密钥本就机器绑定不可迁移，明文入包更违背密钥红线。
- **决策**：导出时数据混入密钥字段即拒绝生成，导入时识别到密钥字段即拒绝写入；素材字节级 base64 随包；导入前确认框+现有数据自动存 `.pre-import.json` 安全网。
- **后果**：换机=备份包+重填一次 Key 两步；不存在"密钥悄悄进包"的路径（test-backup 42 项断言守红线）。

## ADR-014 定时任务：无凭证转「提醒模式」，错过不擅自补发
- **背景**：调度器在本机跑，到点时可能无凭证（48001/未配置）或机器关机；静默失败与擅自补发都不可接受。
- **决策**：无凭证任务到点转「到点·等你复制发布」（系统通知+卡片一键去复制）；关机错过的发布任务（迟于 10 分钟）转「错过时间·等你决定」，仅存草稿类才自动补跑；顺带修复调度器覆盖执行体 `awaiting_confirm` 状态的缺陷。
- **后果**：定时链路任何分支都有显形出口，"最终一按"永远在人手上。
