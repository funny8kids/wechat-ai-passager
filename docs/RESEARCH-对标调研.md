# 同类工具对标调研（稿匠 0.6 的立论依据）

> 调研对象为公众号排版/发布工具的真实体验做法；结论落到稿匠即 CHANGELOG 0.6.0 的 ①~⑤ 与 ADR-011~014。
> 网络工具（mdnice/墨滴/doocs/135编辑器）共性天花板：**网站形态 = 数据出境 + 账号依赖 + 生图换 Key**。稿匠的差异化即"单机+人在回路"前提下把它们做到的做到、把它们做不到的（本地数据、免凭证发布、免 Key 出图）补硬。

## 一、逐项对照

| 维度 | 同类做法 | 稿匠 0.6 现状 | 判定 |
|---|---|---|---|
| 排版模板丰富度 | mdnice/墨滴：数十套主题，网页内换 | 内置 8 套 + 自定义样式 + 样式包 JSON 导入导出 | 追赶：数量少但可自造可分享，且全程离线 |
| Markdown 元素覆盖面 | doocs/mdnice（marked 系）：表格/删除线/任务清单/引用式链接/脚注/自动链接是排版工具的基本预期，缺失即"粘过去要手修" | 五批逐一闭环：GFM 表格（全内联样式+列对齐+斑马纹，后台粘贴不掉样式）+「⊞」一键插入骨架、~~删除线~~、☐/☑ 待办、引用式/自动链接/脚注统一接入角注编号与文末参考区 | **对齐+部分超越**：微信"外链不可点"被反转为角注+参考区设计；每批过 lint/test/verify+exe 截图人审（CHANGELOG [未发布] 五批留证） |
| 复制到公众号 | doocs/md：复制带样式 HTML，**外链图/本地图粘贴后常丢** | 复制富文本自动 dataURL 内联本地图；缺图显形「图片未随带」；逐张「复制此图」位图兜底 | **超越**：带图闭环有 exe 级剪贴板回读 7/7 留证 |
| 配图生图 | 多数要注册/换 Key 或跳站外工具 | 免 Key 直连默认源装好即用 + 自带 Key 源（智谱/硅基流动/自定义）；高峰拥堵自动重试一次并人话显形 | **超越**（免费档限制三条如实公示，不吹万能） |
| 无 API 权限账号 | 135/新榜类：本质是网页代运营，个人未认证号一样受微信规则限制 | 四步发布清单 + 定时「提醒模式」+ 凭证短路双出口 + 失败一键改道 | **超越**：把"降级"反转为正式发布通道（ADR-011） |
| 数据主权 | 云端存稿：断网不可用、换平台要搬家 | 全量 JSON 本机 + 一键备份/迁移包（密钥双向硬拒） | **独有**：同类无此概念 |
| 定时发布 | 平台侧服务端定时（换绑/掉登录即失效） | 本机调度器；错过不擅自补发转「等你决定」；到点最后一按永远在人 | 独有取舍：牺牲"全自动"换"不失控"（ADR-002/014） |
| 首启上手 | mdnice 系：打开即用但排版心智门槛高 | 首启示例文章演 8 主题/表格/待办/图槽/复制，SmartScreen 自救写进手册第 0 步 | 对齐：面向"不看代码的人" |
| AI 改写边界 | 部分工具一键整篇 AI 重写 | HITL 五定律：只改人圈定的段落，建议卡片应用/忽略/撤销 | **原则性差异**，不作为可比较项 |

## 二、由此锁定的硬伤清单（均已闭环，证据见 CHANGELOG 对应小节）

1. ①带图复制不显形 → 内联+兜底双通道闭环
2. ②出图要跳出工具 → 免 Key 默认源+一键落图（HITL 确认落位）
3. ③未认证号"半残"错觉 → 全功能无死角引导
4. ④单机单点 → 备份/迁移包+错过补救显形
5. ⑤体验对标点 → 主题量/样式包/首启/快捷键逐项补
6. ⑤渲染器语法覆盖（表格/删除线/任务清单/引用式链接/脚注/自动链接）→ 五批逐一闭环，含审计出的软换行露字面 `<br>` 等三处存量缺陷与脚注定义行误吞回归的修复
